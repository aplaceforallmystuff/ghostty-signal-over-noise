# CLAUDE.md - ghostty-signal-over-noise

Mid-century modern, retro-futuristic color scheme for Ghostty terminal.

## Overview
A Ghostty terminal theme matching the Signal Over Noise brand aesthetic.

## Structure
```
ghostty-signal-over-noise/
└── signal-over-noise    # Ghostty theme config file
```

## Installation
Copy theme file to `~/.config/ghostty/themes/`

## Color Palette
Based on Signal Over Noise brand - warm tones, readable contrast, retro-futuristic vibe.
